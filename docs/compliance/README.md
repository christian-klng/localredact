# LocalRedact – Compliance-Dokumentation

> **Platzhalter.** Die Dokumente in diesem Ordner sind noch nicht erstellt. Für eine Freigabe nach DSGVO, BSI IT-Grundschutz oder EU-KI-Verordnung sind sie in diesem Stand nicht geeignet.

**Stand:** 20.11.2026

LocalRedact ist ein Fork von [EasyRedact](https://github.com/datenlabor-bmz/easy-redact). Die Compliance-Dokumentation von EasyRedact beschreibt eine Webanwendung mit Cloud-KI und Serverbetrieb. LocalRedact ist eine Desktop-App ohne Cloud-Anbindung, deshalb wurden die übernommenen Dokumente entfernt und durch Platzhalter ersetzt. Jeder Platzhalter nennt, was bereits feststeht und was noch offen ist.

Die Dokumente werden erstellt, sobald die jeweiligen Entscheidungen in [PLAN.md](../../PLAN.md) getroffen und umgesetzt sind. Die rechtlichen Bewertungen (KI-Verordnung, DSFA) brauchen fachkundige Prüfung.

`build-docx.sh` wandelt die Dokumente in DOCX-Dateien um und ist für den späteren Gebrauch erhalten geblieben.
